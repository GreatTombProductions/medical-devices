# Medical Device Safety Check

Search FDA adverse event reports for medical devices and manufacturers. See injury, death, and malfunction counts by device type and manufacturer.

**Live at:** https://greattombproductions.github.io/medical-devices/

## Data Source

[openFDA MAUDE (Manufacturer and User Facility Device Experience)](https://open.fda.gov/apis/device/event/) — 24.7M+ adverse event reports from the FDA's mandatory and voluntary reporting system.

## What This Shows

- **By Device:** Search for any medical device type to see total reports, deaths, injuries, malfunctions, yearly trends, and which manufacturers have the most reports
- **By Manufacturer:** Search for manufacturers to see their device report history and which products generate the most reports

## Important Note

A report does not mean the device caused harm — it means someone filed a report with the FDA. Reporting rates vary by device type, manufacturer, and time period. This is for awareness, not medical advice.
